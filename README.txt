- gacha.html

- album.html（新規）

画像は妖怪20体分が yokai-data.js に組み込み済みなので、妖怪画像の個別アップロードは不要です。
経験値玉の画像 xp50.webp, xp200.webp, xp500.webp, xp1000.webp は既存リポジトリのものを参照します。削除しないでください。

変更内容
・ガチャ排出をオリジナル妖怪20体＋経験値玉4種類に変更
・既存の所持品と経験値玉は削除せず保持（昔のアイテムはもちものの別タブ）

・4つのにっきのナビゲーション／メニューにアルバムリンクを追加

注意
・写真は同じブラウザ／同じサイトのオリジンでのみ共有されます。端末やブラウザを変えると写真が見えない場合があります。
・表示日付は旅程の日付であり、撮影日時のExifではありません。
・すでに保存済みの写真は削除しません。旧京都のOwl Labo写真は「京都・旧予定」として区別します。
・今のメインメニュー（menu.html）は最新版が未提供のため変更していません。メインメニュー内の「大図鑑」ボタンをアルバムへ差し替える場合は最新menu.htmlが必要です。
